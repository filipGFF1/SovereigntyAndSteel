You are building a full Mining Simulator game in Roblox Studio using Lua.  
The style should be classic Roblox (2014–2016 blocky vibe), not ultra-modern.  

### MAP & ARENAS
- Spawn (0m): grassy area with tents, fences, lanterns. Booth with NPC miner "Pickaxes".
- Cave (0–500m): dirt walls, torches. Booth with NPC, Egg pedestal for Cave pets.
- Lava Mines (500–1000m): lava cracks, glowing rocks. Booth "Drills", Egg pedestal for Lava pets.
- Crystal Caverns (1000–1500m): glowing crystals. Booth "Drills", Egg pedestal for Crystal pets.
- Ancient City (1500m+): ruins, statues, glowing runes. Booth "Drills", Egg pedestal for Ancient pets.
- Every 500m a new arena appears. Depth shown in GUI (ex: "Depth: 700m").  
- Teleporter GUI: players can teleport to unlocked arenas.  

### ORES (random generator, not fixed)
Common → Dirt (1), Hardened Dirt (2), Stone (5)  
Uncommon → Coal (10), Iron (25), Copper (40)  
Rare → Gold (100), Obsidian (250), Quartz (400)  
Epic → Ruby (1000), Emerald (2000), Lapis (3000)  
Legendary → Diamond (5000), Hardium (10000)  

### TOOLS – PICKAXES & DRILLS
Players can skip only 2 tools ahead when buying.  
Pickaxes sold in Spawn & Cave:
- Basic Pickaxe (Free, x1)
- Stone Pickaxe (500, x1.5)
- Iron Pickaxe (2,500, x2.0)
- Advanced Pickaxe (10,000, x3.0)
Drills (starting in Lava Mines):
- Basic Drill (50,000, x5)
- Power Drill (250,000, x8)
- Crystal Drill (1,000,000, x12)
- Ancient Drill (5,000,000, x20)

Animations:
- Pickaxe = swing hitting ore.  
- Drill = spinning drill bit, sparks/particles.  

### BACKPACKS
Players can only carry ore until storage is full. GUI shows "Ore: X / Max".  
If full → popup "Backpack Full! Sell ores!"  

- Starter Bag (Free, 5)  
- Small Bag (500, 50)  
- Medium Bag (2,500, 150)  
- Large Bag (10,000, 500)  
- Ultra Bag (50,000, 1000)  
- Legendary Bag (250,000, 1500)  
- Gamepass: Infinite Storage (499 Robux)

### GUI
- Top Bar (center): shows Money, Gems, Depth, Arena Name.  
- Shop GUI (NPC booths):  
  - Tab 1: Gamepasses (2x Money, 2x Mining Speed, 2x Loot, Infinite Backpack).  
  - Tab 2: Tools (Pickaxes/Drills by arena).  
  - Tab 3: Backpacks.  
- Pets GUI: equipped pets (max 3), inventory list, hatch egg button, delete/equip/unequip.  
- Inventory GUI: Skins tab (pickaxe/drill skins), Crates tab (skin crates).  
- Teleporter GUI: teleport to unlocked arenas.  
- Admin Abuse GUI (bottom right, only for creator/admin):  
  - Start Events: Meteor Boss, 2x Luck, Starfall Mutation, Alien Invasion.  
  - Send Global Message button (sends server-wide announcement).  

### EVENTS (Admin Abuse)
- Meteor Boss Event:  
  - Spawns glowing meteor (10,000 HP).  
  - Each hit = 1 damage.  
  - Players with ≥5% damage get rewards:  
    - 10% chance: Meteor Fragment.  
    - 55% chance: 5000 Gems.  
    - 30% chance: Random Skin.  
    - 5% chance: OP Pet (155% stronger than best).  
- 2x Luck Event: +rare ore chance for 5 min.  
- Starfall Mutation Event: 5% ores mutate (x5 value).  
- Alien Invasion: Best miner (most value mined) during event gets Alien Chest (Alien Pet, Skin, Drill Skin, Helmet, Belt).  

### VISUAL STYLE
- Classic Roblox blocky look.  
- NPCs: use Roblox dummy models with miner hats/shopkeeper outfits.  
- Booths: wooden stalls with roof + glowing sign ("Pickaxes", "Drills", "Backpacks", "Eggs").  
- Arenas unique but simple: dirt cave, lava cracks, crystal walls, ruined city.
